# Prompt-History zur Maturaarbeit

Dieses Repository dokumentiert die Nutzerprompts aus den bereitgestellten Claude-Code- und Codex-Sitzungsexporten zum Projekt.

## Dateien

- `Claude_Prompthistory.txt`: 206 Nutzereingaben aus zwei relevanten Claude-Code-Sitzungen.
- `Codex_Prompthistory.txt`: 59 Nutzereingaben aus 13 Codex-Sitzungen; mit der enthaltenen history.jsonl abgeglichen.

Es sind ausschliesslich Nutzerprompts enthalten. Von Nutzern selbst eingefügter Code und Konsolenausgaben bleiben Bestandteil der jeweiligen Eingabe. Antworten der KI-Systeme und automatische Werkzeugausgaben sind nicht enthalten. Bildinhalte konnten nicht als Text rekonstruiert werden und sind gegebenenfalls als Bildnachrichten gekennzeichnet. Zeitangaben beziehen sich auf Europe/Zurich.

Die Vollständigkeit bezieht sich auf die damals bereitgestellten Exportdateien, nicht auf spätere oder andere Chats. Die beiden Textdateien wurden für diesen Upload unverändert übernommen.
